Getting Batch 1 onto Crosslist

Two files go up together: the listing data, and a zip of the photos. The data file is finished and attached in the chat. This page covers making the zip and doing the upload.

The two files

FileWhat it isWhere it comes from
listings.csvAll 15 listings — titles, prices, descriptions, photo namesAttached in the chat. Save it, don't open and re-save it.
images.zipThe 170 photos, renamed to matchYou make it in Step 2 — it's too big to send.

Crosslist matches them by filename. listings.csv says a listing uses 011_1.jpg, and that exact file has to be in the zip. Both are built from the same list, so they already agree — nothing to check.

Four steps

1

Put everything in Downloads

Your Downloads folder needs these four things sitting side by side. Not in sub-folders — loose, together.

Downloads/
  Batch 1          ← the folder of photos
  listings.csv     ← attached in the chat
  items.csv        ← attached in the chat
  mapping.csv      ← attached in the chat

If you saved any of them somewhere else, drag them into Downloads now. That mismatch is the single most likely thing to stop the next step working.

2

Make the zip

Open Terminal — press ⌘ and the spacebar together, type terminal, press Enter. Paste this in and press Enter:

cd ~/Downloads && python3 build.py "Batch 1"

You should see

listings.csv 15 items and images.zip 170 photos, then a Finder window opens showing a build folder.

Takes a minute or so. If it says the zip is over 100 MB and the upload later refuses it, run the same line again with --max-px=1600 on the end — that shrinks the photos, which the selling sites do anyway.

3

Check the build folder

Inside build you want exactly two things:

build/
  listings.csv
  images.zip

There's also an images folder — that's the working copy, ignore it. Don't unzip images.zip to check it. Crosslist needs it zipped, and unzipping is how people end up uploading the folder by mistake.

4

Upload both to Crosslist

In Crosslist, find the bulk import or CSV import — the same place the template spreadsheet came from. Give it both files in the one import: listings.csv first, then images.zip.

Don't upload the CSV on its own and add photos after. The whole point of the filenames is that Crosslist attaches them for you.

You should see

15 draft listings, each with its photos already attached in order — front, back, close-ups, then any flaw shots last.

If something goes wrong

items.csv is not in this folder

One of the three CSV files isn't in Downloads. Find it and drag it in, then run Step 2 again.

No such file or directory

The photo folder isn't called exactly Batch 1. Type cd ~/Downloads && python3 build.py with a space at the end, then drag the folder from Finder straight into the Terminal window — it fills in the name correctly.

Most likely a column it wants that's deliberately blank — shipping weight is the usual one. Paste the exact error to me; it's a quick fix and you re-download one file.
